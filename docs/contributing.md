# Contributing to GolfMike

Thank you for your interest in contributing to GolfMike! We welcome contributions from the community.

## Getting Started

1. **Fork the repository** on GitHub
2. **Clone your fork** locally:
   ```bash
   git clone https://github.com/your-username/golfmike.git
   cd golfmike
   ```
3. **Create a branch** for your feature:
   ```bash
   git checkout -b feature/your-feature-name
   ```

## Development Setup

1. **Start the development environment**:
   ```bash
   docker-compose up -d
   ```

2. **Run tests**:
   ```bash
   python check_system_status.py
   python test_weather_api.py
   ```

3. **Make your changes** and test them thoroughly

## Contribution Guidelines

### Code Style
- Follow Python PEP 8 style guidelines
- Use meaningful variable and function names
- Add comments for complex logic
- Include docstrings for functions and classes

### Commit Messages
- Use clear, descriptive commit messages
- Start with a verb in imperative mood
- Reference issues when applicable

### Pull Requests
- Create a clear, descriptive title
- Provide a detailed description of changes
- Include screenshots for UI changes
- Reference any related issues

## Areas for Contribution

### Features
- Enhanced weather visualization
- Mobile-responsive improvements
- Additional data source integrations
- Performance optimizations

### Documentation
- API documentation improvements
- Tutorial guides
- Code examples
- Architecture diagrams

### Testing
- Unit tests
- Integration tests
- Performance tests
- End-to-end tests

### Bug Fixes
- Report bugs via GitHub issues
- Include steps to reproduce
- Provide system information
- Test fixes thoroughly

## Development Workflow

1. **Create an issue** to discuss your contribution
2. **Fork and clone** the repository
3. **Create a feature branch**
4. **Make your changes**
5. **Test thoroughly**
6. **Submit a pull request**

## Code Review Process

- All contributions require review
- Address feedback promptly
- Keep pull requests focused and small
- Ensure tests pass

## Questions?

- Create an issue for questions
- Check existing documentation
- Review closed issues for similar questions

Thank you for contributing to GolfMike!
